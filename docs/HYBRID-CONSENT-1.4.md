# RODINNÝ ŠTÍT — Hybrid Consent 1.4 / Owner QA

**Дата:** 01.11.2026  
**Статус:** реализация в отдельной GitHub-ветке, не релиз.  
**Ветка:** `feature/hybrid-consent-1.4`  
**База:** `feature/scam-quality-1.3-hardening`.

## Цель

Соединить локальную проверку с добровольным уточняющим AI-анализом, **не выдавая отсутствие срабатываний правил за безопасность**. Использовать существующий сервер `/api/analyze`, а не вводить второй сервис или новые расходы.

## Сценарий

1. SMS/e-mail анализируется локально. Без сетевого запроса, текст не передаётся серверу.
2. Если результат **LOW** («очевидных сигналов нет») или **MODERATE** (неоднозначно), а защищённый Vercel Preview сообщает, что AI доступен, появляется блок «Chcete druhý názor?».
3. Кнопка только возвращает к исходному тексту, выбирает режим AI и открывает **маскированный предпросмотр**. Она не отправляет запрос.
4. Галочка согласия изначально выключена; изменение редактируемого текста аннулирует её. Согласие связано с **точным содержимым маскированного текста**.
5. Только повторное явное нажатие «Zkontrolovat pomocí AI» с актуальным согласием создаёт один запрос через существующий API.
6. После запроса согласие сбрасывается независимо от исхода. Если пользователь успел изменить текст до ответа, старый ответ не показывается.
7. Если сервер недоступен, выдаёт ошибку или исчерпал квоту — без выдуманного AI-результата, доступна локальная проверка.
8. При **HIGH** локальная оценка и рекомендации не заменяются предложением AI: важный сигнал не следует пытаться «опровергнуть» вторым мнением.

## Ограничения и честные предупреждения

- Никакой автоматической отправки сообщений или снимков экрана AI. OCR остаётся локальным.
- Маскирование не безошибочно: пользователь должен проверить текст перед согласием. Не вводить пароли, PIN, одноразовые коды.
- Ни локальные правила, ни AI не проверяют личность отправителя, подлинность ссылки, счёта или фотографии.
- Отмена сетевого запроса может не остановить обработку уже переданного сообщения провайдером. Интерфейс прямо это сообщает.
- Никакой сохранённой истории сообщений, Service Worker или аналитики.
- AI показывается только при **фактической доступности** API на защищённом Preview. Публичный GitHub Pages не получает эту функцию.
- Независимая проверка алгоритма 1.3 B дала **32/60 совпадений с ожидаемой оценкой на синтетической выборке**; это недостаточно для публичных заявлений о надёжной защите.
- Новая функция «второе мнение» не исправляет сама по себе пропущенные угрозы локального классификатора. Её следует рассматривать как дополнительный пользовательский инструмент, а не гарантию.

## Технический QA

- Исправлен сбой отображения сигналов версии 1.3 без поля `pattern` (только `example`). Подсветка дословных цитат экранируется от HTML/regex-инъекций.
- **120/120** разработческих сценариев классифицированы ожидаемо при прямом исполнении JS в изолированном инструменте, проверены наличие цитат и число рекомендаций.
- Имитация браузера: локальный путь без сети, показ предложения LOW, отсутствие предложения HIGH, переход к предпросмотру, аннулирование согласия после правки, один мок-запрос и fallback при сетевой ошибке.
- В `tests/hybrid.test.cjs` записаны **10 автоматических тестов**, `npm test` расширен ими.
- Код новых тестов синтаксически разобран; **полный Node `npm test` пока не выполнен**, реальный Android и Vercel Preview этого коммита ещё не проверены.
- Визуальная композиция и CSS анимации Pilot 1.1 побайтно совпадают с базовой веткой 1.3 в соответствующих секциях.

## Проверка владельцем после появления защищённого Preview (без платных вызовов)

1. Открыть Pilot на Android и убедиться, что Прага/телефон/кольцо/щит не изменились.
2. Ввести `Pošli mi fotky z oslavy, prosím.` — локальный LOW. При доступном сервере: блок с добровольной AI-проверкой.
3. Нажать «Prohlédnout text před AI kontrolou»: увидеть исходное сообщение и предпросмотр, **согласие выключено**.
4. Изменить текст после выбора согласия — галочка должна сброситься.
5. Ввести вымышленное высокорисковое SMS `Ahoj mami, mám nové číslo. Pošli 5000 Kč ještě dnes, nevolej.`: красный HIGH, кнопки второго мнения нет.
6. Проверить режим с выключенным AI: никакой кнопки второго мнения; локальные правила работают.
7. Не нажимать кнопку реальной отправки AI, пока отдельно не утверждены бюджет, ограничение вызовов и режим теста.
